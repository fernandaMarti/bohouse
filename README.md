## Descripción

Esta es una página web estática creada con HTML y CSS. La página está dedicada a la decoración de estilo bohemio, ofreciendo ideas, inspiración y consejos para quienes deseen incorporar este estilo en sus hogares.

## Contenido

La página web incluye las siguientes secciones:

1. **Inicio**: Una introducción al estilo bohemio, con una breve descripción y una imagen destacada.
2. **Nosotros**: Acerca del blog de decoración bohemia para inspirarte.
3. **Mas hogar**: Consejos y trucos sobre cómo incorporar el estilo bohemio en diferentes partes de la casa.
4. **Contacto**: Un formulario de contacto para que los visitantes puedan enviar preguntas o solicitar más información.
